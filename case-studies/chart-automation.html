BT AI Tools — Internal finance AI tool

An internal AI tool for creating finance charts — one system that turns source data into print-ready PDFs, preview images, and Datawrapper payloads, and that people or agents can call the same way.

Problem

Finance charts were created in more than one place: a web app and scheduled jobs each kept their own drawing logic. Copies drifted — inconsistent house style, duplicated adapters, and slower visual QA before a chart could ship.

Approach

BT AI Tools is the internal finance chart creation layer. I helped centralize it as a Python package with a clear model: chart family → brand profile → recipe → renderer. Callers own data access, secrets, and delivery; the tool owns “how to draw a finance chart” and “how to assemble a publish payload.” 

source data → adapter → canonical payload
canonical payload + recipe → renderer
recipe = family + brand skin + output target + eval policy

What it produces

  • Print PDF — editable/vector finance charts with print size and color constraints
  • Preview PNG — fast review artifact for humans and evals
  • Datawrapper payload — CSV + metadata for dry-run or publish

The same recipe can be run from a CLI, HTTP API, or MCP server, so editors, jobs, and AI agents create charts through one contract.

Coverage snapshot

Quality bar

Print PDF is the canonical finance chart. Fixtures + hard visual references gate merges; heatmaps and side-by-side diffs are review aids, not silent overwrite paths. Coverage states make it obvious which recipes are production-protected versus diagnostic-only.

Impact

  • One internal AI chart tool instead of copied renderers across apps and jobs
  • Brand skins selected by recipe — finance chart logic stays brand-agnostic
  • Editors and agents create the same chart through skill / MCP / API

Stack

Python 3.10+, ReportLab, Datawrapper payloads, pytest / chartbook fixtures, optional FastAPI-style HTTP and MCP adapters.
